# スーパー日本十進分類カルタ オフライン版

表示される3桁の日本十進分類法（NDC）の番号を見て、対応する分類の札を取るゲームです。インターネットに接続せずに遊べます。

## ダウンロード

配布元のGitHubページで `Releases` を開き、最新リリースの `Assets` にある `offline.zip` をダウンロードしてください。

すでにZIPファイルをダウンロードした方は、以下の「はじめかた」へ進んでください。

## はじめかた

1. ダウンロードしたZIPファイルを展開します。
2. 展開したフォルダにある `index.html` をWebブラウザで開きます。
3. 遊びたいモードを選び、`GAME START` を押します。

ZIPファイルの中から直接開かず、先に展開してください。画像・音声なども必要なため、フォルダ内のファイルはまとめて保管してください。

展開した `offline` フォルダの構成は次のとおりです。ゲームを始めるときに開くのは `index.html` です。

```text
offline/
├── index.html   ← これを開いて遊びます
├── README.md    ← 遊び方と利用条件
├── assets/      ← ゲームに必要なファイル
└── docs/        ← 使用素材とライセンスの説明
```

`assets` と `docs` は、そのまま同じ場所に置いておいてください。

## 遊びかた

数字を見たり読み上げを聞いたりしながら、対応する札をクリック、またはタップします。詳しいルールはゲーム画面の `HOW TO PLAY` で確認できます。

| モード | 内容 |
| --- | --- |
| HI SCORE MODE | 全10ラウンドでハイスコアに挑戦します。 |
| VS CPU MODE | CPUと札を取り合います。難易度は `CPU LEVEL` で選べます。 |
| ENDLESS MODE | ライフが尽きるまで、10ラウンドごとのWAVEに挑戦し続けます。 |

パソコンではキーボードでも札を取れます。初期設定は、上段の左から `Q W E R T Y`、下段の左から `A S D F G` です。`KEY CONFIG` で割り当てを変更でき、`SHOW KEY LABELS IN GAME` で札のキー表示を切り替えられます。

音声は `SOUND` でオン・オフを切り替えられます。読み上げの声は `VOICE A` / `VOICE B` から選べます。

## 個人ランキング

HI SCORE MODEとENDLESS MODEでは、それぞれ上位5件のスコアを保存します。タイトル画面の `RANKING` とゲーム結果から確認できます。オンラインランキングやスコア送信の機能はありません。

記録は遊んだブラウザに保存されます。別のブラウザを使う、フォルダの保存場所を変える、ブラウザの保存データを消去するなどにより、過去の記録が表示されなくなる場合があります。プライベートブラウズなど、保存が制限される環境では記録が残らない場合があります。

## うまく動かないとき

- 音が出ない場合は、`SOUND` がオンになっているか、端末の音量が十分かを確認してください。ブラウザによっては、画面上のボタンを押した後に音声再生が有効になります。
- 画像や音声が読み込まれない場合は、ZIPをすべて展開し、フォルダ内のファイルを移動・削除していないか確認してください。
